# Automatización con Power Automate y Copilot Studio para gestión de proyectos

## Plataforma de laboratorios

Te damos la bienvenida a la **plataforma de laboratorios** del curso **Automatización con Power Automate y Copilot Studio para gestión de proyectos**. Aquí podrás automatizar el seguimiento de actividades, consolidar información para reportes y utilizar agentes para analizar requerimientos y gestionar la revisión de documentación técnica mediante prácticas guiadas.

## Lista de laboratorios

Cada uno de estos laboratorios está diseñado para ofrecerte una experiencia práctica. Haz clic en los enlaces para comenzar.

### Capítulo 1

#### [Práctica 1. Crear un flujo básico de seguimiento que detecte un cambio en una lista de SharePoint, evalúe el estado de una actividad y envíe una notificación automática por correo.](Capitulo01/README.md)

- **Descripción:** Crearás un flujo en Power Automate que detecte modificaciones en una lista de SharePoint, evalúe el estado de las actividades y notifique automáticamente por correo.
- **Duración estimada:** 35 min.

### Capítulo 2

#### [Práctica 2. Consolidar información de una lista de SharePoint y un archivo de Excel, filtrar actividades relevantes, generar un resumen de estado con contenido estructurado para reporte o presentación y distribuirlo automáticamente por correo.](Capitulo02/README.md)

- **Descripción:** Integrarás datos de SharePoint y Excel, filtrarás actividades bloqueadas e hitos en riesgo y generarás un reporte HTML para almacenarlo en SharePoint y distribuirlo mediante Outlook.
- **Duración estimada:** 65 min.

### Capítulo 3

#### [Práctica 3. Crear un agente que utilice un documento de requerimientos almacenado en SharePoint para proponer criterios de aceptación, condiciones de entrada y salida, preguntas pendientes y un checklist de QA para revisión del equipo.](Capitulo03/README.md)

- **Descripción:** Configurarás un agente en Copilot Studio utilizando documentación de SharePoint para generar criterios de aceptación, condiciones, preguntas pendientes y un checklist de QA, validando la calidad de sus respuestas.
- **Duración estimada:** 75 min.

### Capítulo 4

#### [Práctica 4. Analizar documentación técnica con Copilot Studio, generar el documento paso a paso de un proceso de despliegue y enviarlo a revisión mediante Power Automate. La práctica documenta el pipeline y sus controles, pero no ejecuta un pipeline de CI/CD.](Capitulo04/README.md)

- **Descripción:** Utilizarás Copilot Studio para generar un procedimiento de despliegue, almacenarlo en SharePoint e integrar un flujo de Power Automate como herramienta del agente para solicitar su aprobación documental mediante Approvals y notificar el resultado por Outlook.
- **Duración estimada:** 75 min.

**Duración total de los laboratorios: 250 minutos (4 horas y 10 minutos).**
