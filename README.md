# Automatización con Power Automate y Copilot Studio para gestión de proyectos

Curso práctico de 7 horas para gestores de proyectos y profesionales que colaboran con equipos de QA, BA y TI. Los participantes utilizarán Power Automate con conectores estándar de Microsoft 365 y Microsoft Copilot Studio Trial para automatizar comunicaciones y reportes, analizar requerimientos y generar documentación de procesos técnicos.

## Accesos rápidos

## Lista de laboratorios
